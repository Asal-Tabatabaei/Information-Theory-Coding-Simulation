# Information Theory & Coding Simulation

A Python-based simulation project for the **Information Theory & Coding** course at the University of Isfahan.

The project simulates a complete digital communication chain, including **source coding, channel coding, noisy transmission, decoding, and performance evaluation**.

## 📌 Project Overview

The main goal of this project is to study digital information transmission through a **Binary Symmetric Channel (BSC)** and compare coded and uncoded transmission.

The simulation includes:

- Dynamic Huffman source coding
- Hamming channel coding
- Binary Symmetric Channel (BSC)
- Hamming syndrome decoding and error correction
- Bit Error Rate (BER) evaluation
- Signal-to-Noise Ratio (SNR) analysis
- Shannon limit comparison

Run the program:

🧩 Program Options

The program provides four simulation modes:

1. Dynamic Huffman Coding

Generates Huffman codes based on source symbol probabilities.

2. Hamming Matrix Generation

Generates the generator and parity-check matrices for a Hamming code.

3. BSC Channel Simulation

Simulates bit errors through a Binary Symmetric Channel (BSC).

4. Full Communication Chain

Runs the complete system:

Huffman Coding → Hamming Coding → BSC → Decoding → BER/SNR Analysis → Shannon Limit Comparison
